# [0.5.0](https://github.com/kubeflow/sdk/releases/tag/0.5.0) (2026-08-07)

This is Kubeflow SDK 0.5.0 release.

```
pip install kubeflow==0.5.0
```

Kubeflow SDK now supports `PipelinesClient()` for Kubeflow Pipelines APIs and `SparkClient()`
for interactive sessions and Spark batch job submissions. Learn more about the recent highlights in
these blog posts:

- [Kubeflow SDK Evolution - One Million Downloads and Counting](https://www.cncf.io/blog/2026/08/03/kubeflow-sdk-evolution-one-million-downloads-and-counting/)
- [Batch Jobs for SparkClient: Submitting and Managing Spark Workloads from Python](https://blog.kubeflow.org/sdk/spark-batch-jobs/)
